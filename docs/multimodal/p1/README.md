# 多模态扩充 P1 · PDF 解析改进

2026-11-09 本地实跑，2026-11-10 记录。固定题集的 9 道标注待人工确认，以下为暂定证据覆盖分。

## 改动

- PDF 表格中，下划线被拆到单独一行时，用原生文字层核对同一单元格。只有非下划线字符的顺序及下划线数量都一致，且文字符合标识符形态时才采用原生文字，保留表格行列和视觉换行。
- 对带文字的矢量框，依据直线和三角箭头识别方向。两端都必须唯一对应到文字框，才在草稿中输出可检索关系，保存页码、箭头及两个节点框坐标。保留矢量图待核对警告。
- PDF 新草稿使用 `structured-binary-v2`，可继续导入已核对的 v1 草稿。复跑中五份 DOCX 的草稿摘要一致，PDF 正文、表格结构、原件和预览也与 P0 对齐。

## 同口径对照

沿用 [P0](../p0/README.md) 的 9 份原件、9 道 dev 题、切片、bge-small、BM25、RRF 及上下文预算。仅更换解析表示，使用独立 KB、SQLite 和 Milvus 集合。复跑的 18 次请求均返回 HTTP 200，外部模型调用和隔离台账均为 0。

- 目标字段标识符恢复并进入 Top 5。按单独口径看，标签和取值表达式在两版都进了 Top 5，两版都被上下文组装跳过。字段保真改善与原题覆盖分别记录。
- 三道图题所需的六条定向关系均进入草稿。五条进入 Top 5，只有其中一道题的两条关系同时进入最终上下文。其余三条已召回关系被预算挡住。
- 一道表格题仍只命中正确页。另一道表格题仍在 Top 5 找齐证据，关键正文因预算未进最终上下文。这两项保留为后续独立对照。

## 复跑与边界

代码回归覆盖字段保真、反阅读顺序的箭头、无箭头连线和 v1 草稿兼容。可运行 `python -m pytest tests/unit/test_binary_readers.py -q`。业务对照脚本 `run_p1.py`、原件摘要、解析差异、接口轨迹及逐点评分在 P1 本地任务目录。复跑依次执行 `setup`、`live --run <新运行名>`、`score --run <同一运行名>`，使用项目现有 venv 和健康的本机 Milvus。

已验证的图样本是线性矢量图。复杂分支条件、折线连线、扫描件 OCR 和图片语义仍需各自的样本与实现。当前结果描述证据覆盖，生成答案的验证留给后续阶段。
