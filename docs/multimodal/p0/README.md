# 多模态扩充 P0 · 基线诊断

实跑日期 2026-11-09。基线运行和诊断已完成，9 道题的标注待人工确认，以下分数为暂定结果。这里的 P0 是多模态扩充的基线阶段。

## 固定基线

- 语料为 9 份本地原件。诊断集包含正文、表格、流程图各 3 题，只使用 dev。原件版本、题目、审核记录与逐题轨迹保存在本地任务目录。
- 使用现有 PyMuPDF 和 DOCX 读取器，保留原始解析产物与来源映射。切片上限为父片段 1600 字符、子片段 600 字符。
- 使用独立 KB 和 runtime，在本机 Milvus 发布。本地 bge-small-zh-v1.5 和 BM25 各取 Top 5，经 RRF 融合，`k=60`。开启父片段扩展，上下文预算为 6000，按项目现有估计方法执行。
- 9 道题的搜索及上下文预览共 18 次请求，均返回 HTTP 200。语料缺口为 0，外部模型调用为 0。评分对象为证据覆盖，答案生成对照留到 P4。

## 暂定结果

| 题型 | 解析保留要点 | Hit@5 | Top 5 覆盖要点 | 上下文覆盖要点 | 上下文覆盖全题 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 正文 | 5/5 | 3/3 | 5/5 | 5/5 | 3/3 |
| 表格 | 7/8 | 2/3 | 3/8 | 2/8 | 0/3 |
| 流程图 | 0/6 | 0/3 | 0/6 | 0/6 | 0/3 |
| 合计 | 12/19 | 5/9 | 8/19 | 7/19 | 3/9 |

- 解析阶段保留了流程图的节点文字，未显式保留六条定向关系。三道图题的正确页均进入 Top 5，表中的 Hit@5 按有效定向证据计分。图题均为线性流程，分支判断还需补充样本。
- 一处表格字段标识符在解析中发生字符错排，同行的标签和取值表达式仍在。暂定口径将标识符保真计入了该题的一个必答点，后续评分应分开记录原件保真和题目证据覆盖。
- 另有一题在检索阶段命中了正确页，但未命中目标表格行。一题在 Top 5 找齐证据，组装时因预算未选入关键段落。预算遗漏已用原组装函数复现。

## P1 验证目标

用同一版语料、题目、切片和检索配置比较解析方案。先检查字段标识符是否准确、箭头方向和节点关系是否有可回查的表示，再比较召回和上下文覆盖。保留正文题作回归对照，并把表格目标行召回和上下文预算遗漏单独记录。

## 阶段留痕约定

P1–P5 每个阶段完成后，在 `docs/multimodal/pN/README.md` 新增该阶段记录。记录阶段目标、实际改动、语料和题集版本、评分规则、复跑方法、关键结果、限制及人工审核状态。完整运行记录继续在本地任务目录保存。

补题或调整评分规则时生成新版本，保留旧结果。仅调整规则时可基于同一原始结果重评分。新增题目时，用同一版题集和规则重跑基线与对照方案。用于调试的题留在 dev 或回归集中，最终验收沿用独立的 test。
