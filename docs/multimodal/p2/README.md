## 本阶段改动

- 本机页面支持逐份上传 PDF 或 DOCX、查看后台解析状态、下载原件、查看 PDF 原页预览和审核提取草稿。任务与失败原因持久化，中断或失败可以重试。遇到解析警告，需要明确接受已知缺失。
- 选择同库已审核草稿，准备完整资料集。已有资料集的替换需要确认。发布沿用索引构建任务，校验通过后才切换发布指针。网页上传的资料仅允许本机处理。
- 原问题明确点名文档和表格行或流程节点时，额外召回同版本证据。流程节点可沿同页的已解析箭头延伸一跳。原 dense 和 BM25 各取 5，结构化路径最多取 3，在同一次 RRF 中分别按权重 1、1、2 融合，`k=60`。
- 组装仍以融合 Top 5 为范围。先放入子片段，明确匹配点名文档和表格行或节点的片段优先，再用剩余预算尝试父扩展。提示词里的位置压缩为页码或正文块，接口和引用回查保留完整原件坐标。预算仍为 6000。
