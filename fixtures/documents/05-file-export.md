# 演示文件导出

本文为 demo-v1 模拟业务说明，不涉及真实用户文件或公司导出协议。

## 输入与输出

输入为当前演示会话中的相机状态记录，字段仅包含模拟设备标识、阶段和演示时间。导出前必须检查脱敏结果，不得包含账户、密钥、真实设备序列号或用户路径。输出为 UTF-8 文本文件，首行说明 data_kind=simulated 和 app_snapshot=demo-v1。

## 操作流程

1. 在调试页选择“文件导出”，选择“当前会话模拟记录”。
2. 预览即将写出的字段，确认记录属于当前会话。
3. 点击导出后先生成应用临时文件，成功后再交给系统保存选择器。
4. 用户选择保存位置并确认后显示成功；用户取消时显示已取消。
5. 导出失败时显示脱敏错误提示，并清理本次临时文件。

## 结果判断

没有可导出记录时提示“当前会话无记录”，不生成空的成功文件。用户取消与写入失败都不能显示导出成功。文件是否存在、编码是否正确、字段是否完整需要实际打开检查，单凭按钮反馈不能作为完整验收证据。

## 清理与边界

成功交付或取消保存后都清理临时副本。已经由用户保存的文件由用户管理，不因临时清理而删除。当前流程不自动上传文件；不包含目录批量导出、压缩打包或后台重试。
